Получение личного тестового сертификата

Тестовая страница для КриптоПро ЭЦП Browser Plug-in. При создании ключевого контейнера разрешаются только считыватели, имя которых начинается с pkcs11_.

Фильтр: ^pkcs11_.*
Перед созданием ключевой пары вызывается CAdESCOM.About.ReaderFilter. Все считыватели, не попавшие под регулярное выражение, полностью запрещаются для этой операции.

1. Создать ключ и запрос PKCS#10

Вторая кнопка сама получает список режимов считывателей, оставляет только имена, начинающиеся с pkcs11_, и передаёт полное имя найденного считывателя в CX509PrivateKey.ReaderName. Окно выбора носителя не вызывается.

Открыть тестовый УЦ (HTTPS) Открыть тестовый УЦ (HTTP)

В тестовом УЦ выберите отправку готового запроса PKCS#10/PKCS#7, вставьте созданный запрос и получите сертификат. HTTPS-вариант тестового УЦ требует браузер с поддержкой ГОСТ TLS; при необходимости используйте HTTP-вариант.

2. Установить выданный сертификат

Что именно проверяется

Первая кнопка проверяет сценарий с ReaderFilter и системным окном выбора носителя. Вторая кнопка работает без этого окна: получает режимы считывателей через CCspInformation.GetReaderModes(), фильтрует их по префиксу pkcs11_, выбирает первый найденный режим и задаёт его полное имя в CX509PrivateKey.ReaderName перед созданием ключа.
